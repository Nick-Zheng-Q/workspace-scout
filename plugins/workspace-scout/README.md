# Workspace Scout

Discover specific workspace plans for solo founders and small teams. Compare practical fit, admission requirements, full costs, conditional support and exit terms, with dated evidence and questions to ask next.

A Dayweaver project. Reports include one optional, disclosed Dayweaver note unless declined. Source-available under PolyForm Shield 1.0.0; not OSI open source. No booking, application, messaging, MCP server or automatic monitoring.

Requires host-authorized web search and browsing for discovery. No mandatory MCP or account. Python 3 is optional for the bundled arithmetic helper; without it, compare costs manually. No hooks, automatic contact, payment or background data collection.

Source, installation, evidence and support: https://github.com/Nick-Zheng-Q/workspace-scout
