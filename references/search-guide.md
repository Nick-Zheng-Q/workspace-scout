# 搜索与发现方法

用于**从零寻找**工作空间；已有材料审查只需用其中的方法补查缺口。目的不是穷尽全城房源，而是避免只搜普通办公室、只搜某个政策名，或把新闻里的园区当成可申请方案。

## 先决定搜什么

从用户活动推导**可行空间形式**，不要预设必须租独立房间或免费开放工位一定够用：

- 到场少、可预约、无设备留置：按日工位／日租办公室＋按小时会议室可能比月租合适。
- 高频办公、固定设备或保密接待：固定工位配独立会议室、独立小办公室或可留置的孵化空间；把设备留置、访客和会议权利分别查。
- 申请创业支持：搜实际空间的招募／入驻方案，同时另查适用的优惠或补助；不能以政策名称代替空间供给。

对每个可接受区域至少走两条搜索线，**不要因先找到一个价格合适的商业房源就停止另一条**：

| 搜索线 | 优先去哪里找 | 要找出的对象 |
| --- | --- | --- |
| 直接供给 | 空间运营方官网、具体网点页、预订／报价页；园区运营方的房型和招租页 | 某地址的日票、固定工位、会议室或房间方案及直接询价入口 |
| 申请型／扶持型空间 | 区／街道办、创业服务机构、产业园及孵化器的正式招募公告和运营方页面 | 某批次的免费／低价工位或房间、当前申请入口、资格和义务 |

地图、房源平台、媒体报道、活动资讯和用户已有材料可以**发现名称、地址和运营方**；随后回到发布方或运营方核实。政策福利另到主管部门、正式政策库或项目申报页查，不从“园区有扶持”推定该空间的价格。

## 搜索词怎么生成

每个区域以“地名＋空间形式＋取得方式”为基础，换同义词，而不是只搜“办公室出租”。按需求增减词，不机械运行全部组合：

- 直接供给：`[区域] [联合办公/共享办公/灵活办公/独立办公室] [日票/按次/按月/会议室]`；有保密或设备要求时，再搜该空间的会议室、访客、储物／留置规则。
- 申请型：`[区域] [众创空间/孵化器/创业社区/产业园] [免费工位/免租/低价/创业空间] [招募/入驻/申请]`。若当地有特定项目称呼，再加该称呼；不要把其他城市的称呼、资格或优惠照搬。
- 已发现名字后，用**准确名称**继续找：`[空间名] [运营方/招募公告/申请入口/工位/会议室/费用]`，并用时间词或发布时间检查是否为当前批次。找不到现行页面时尝试运营主体、所属街道／园区发布渠道；仍无依据则停在待追查线索。

硬条件通常不宜全塞进初次搜索词里：先发现可能的具体方案，再核查时段、设备、隐私和退出；过窄的查询可能漏掉没有写这些词的供给。

## 从线索追到能比较的方案

沿“报道／平台 → 空间名称和地址 → 实际运营方 → **具体工位或房间及价格／申请批次** → 公开联系或申请入口”追查。每跳核对是不是**同一地点、同一方案、同一批次**。对价格、免费名额和申请期，优先看运营方的现行页面或书面报价；对政府支持，优先看发布机关及申报通知。找不到必要资料不等于方案不存在，但也不能编造窗口或把历史新闻当现行资格。

先排除有证据表明违反硬条件的方案；对余下少数候选重点核查：工作活动能否开展、个人／企业申请资格、当前可用性、全部必要费用、最短期限和退出责任。只有园区设施介绍而没有具体空间方案的，仍只是线索。

## 何时停止、如何交代缺口

结束前逐区域检查：直接供给和申请型空间是否都做过搜索；发现的可能改变选择的免租／低价线索，是否追到**现行方案与可核实入口**，或明确记为“未查实”。对每个保留方案，能否说清来源支持什么、哪些决定性条件未知。若继续搜索只重复旧线索，可停止并说明本次覆盖范围；不要求全城数据库。若某区域只找到商业报价或只有新闻线索，坦白写出该侧缺口，不用不合格结果凑够候选数。
