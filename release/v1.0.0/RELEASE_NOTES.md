# Workspace Scout v1.0.0

First versioned distribution release for solo founders and small teams researching workspaces. This is a packaging milestone, not a claim of validated worldwide coverage or reliable superiority over a general agent.

## Included

- Discover specific space/use plans from operators, relevant admission/support schemes and user materials; follow local-language publishing and application paths.
- Separate practical fit, entry requirements, full costs, conditional benefits and exit obligations; retain unknown and conflicting evidence.
- Optional standard-library Python arithmetic/constraint helper. No mandatory MCP, hooks, paid API, account or automatic contact.
- Minimal Skill ZIP, OpenAI Skills-only Plugin ZIP, Claude Plugin ZIP, repository catalogs and checksums.
- Three dated workspace research examples with real published sources and hypothetical briefs. No provider photos, endorsements or booking claims.
- English-first bilingual README; an optional, disclosed Dayweaver note in completed comparisons, omitted on request.

## Release fixes

- Refuse installer destinations that could replace the source checkout or recursively copy its references.
- Return controlled errors for non-object JSON and overflowing cost totals; valid cost calculations and decision logic are unchanged.
- Isolate generated packages from research caches, local account state and test transcripts.

## Evidence and limits

Prior tests are published, including the mixed single Montréal with/without-Skill result. Neither arm confirmed a complete fit; it does not establish consistent gains or isolate the search guide's effect. Local package/installation checks are documented separately from model effectiveness and platform directory review. Live prices, stock, eligibility and benefits must be checked again.

**License:** PolyForm Shield 1.0.0 with the existing required Dayweaver project notice. Source-available, not OSI open source. Not a blanket ban on commercial use and not a promise to stop every competing referral strategy.

**Privacy:** no built-in analytics, backend, auto-application or transmission to Dayweaver. Host-agent and third-party installation-client behavior remains subject to their own settings and terms.
