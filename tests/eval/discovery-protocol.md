# 工作空间发现能力对照协议（测试前固定）

## 比较对象与隔离

同一请求分别给两个独立执行者：旧版 `case-d/skill-before-search-guide.md` 与当前 `SKILL.md`＋`references/search-guide.md`。不提供评分表、预计答案、其他组输出或已知线索。每组可使用公开网络，不可联系、申请或发送资料。测试请求要求简短列出实际检索的**地区×来源类别、代表性搜索词／入口及未查实处**，而不是只报最终候选。顺序为：先固定指标和案例，再运行，再核验来源，最后决定修改。

## 先看结果质量，再看候选数量

每个地区的**直接供给**与**申请型空间**分别记录：

| 指标 | 记录方式 |
| --- | --- |
| 搜索覆盖 | 是否有可复核的运营方／官方来源；若未找到，列出实际检索入口和未查实状态。不能把“没找到”写成“不存在”。 |
| 具体方案 | 地点、运营方、日票／工位／房间或招募批次能否对应；仅园区名称不计。 |
| 线索追查深度 | 0＝只有名称；1＝具体空间或方案；2＝发布方／运营方的对应页面；3＝现行价格或招募条款及公开联系／申请入口；4＝进一步找到本用户关键资格、必要费用和退出条款。逐条记录最高证据层级，不能仅凭回答自述加分。 |
| 可行动对象 | 公开入口真实、方案与用户活动没有已知硬冲突且决定性未知可具体询问，才计“值得联系”；新闻线索另计。 |
| 错误 | 链接打不开或不支持所引事实、拼接不同批次／房型、过期项目当现行、未获批优惠冲抵费用、违反硬条件仍推荐，逐项记录。 |

综合观察不使用一个总分替代证据：报告两组各区的最高追查层级、值得联系对象数量、待追查线索数量、事实错误和实际行动问题。不同案例公开供给可能不同，**不得以免费方案的绝对数量或答案篇幅判优**。如果两组都找不到现行项目，诚实标未知是正确行为；只有经独立复核存在相应公开页面却遗漏时，才记录遗漏。

## 来源核验与解释

抽查每组所有决定结论的申请型来源及至少一个商业来源：打开原链接，确认日期、主体、地址、具体方案与所引条款。仅新闻报道不能证明现行可申请，运营方起价也不能证明目标月度总价。对无法打开但存在搜索摘要的页面标“未复核”，不视为已证实或自动判伪。

每个业务案例只有一轮输出；不据单例宣称稳定提升。只有跨案例重复的同类遗漏才建议修改 Skill；若新版无明显收益，不继续堆指令。自动触发另测，不与显式指定使用 Skill 的能力测试混为一谈。
