# 最小有／无 Skill 对照（2026-09-23）

## 方法与边界

- 两个虚构、互不相同的“已有材料审查”任务：Case A（两人设计咨询，设备留置和保密会谈）、Case B（一人软件咨询，按月退出是硬条件）。测试执行者只读各自请求和模拟来源，不联网、不联系机构。
- 每例各由两个独立 agent 回答：基线组不读 Skill；Skill 组读 `SKILL.md` 及其相关引用文件。两组都未看到预先写好的 `rubric-a.md` / `rubric-b.md`；评分在完成后进行。评分只看可观察输出，不按篇幅或格式奖励。
- 本测试检验**材料对齐、条件判断和表达**，不检验主动网上找候选、搜索覆盖、时效核查、Skill 自动触发或真实运营方联系。两例、每例一轮不足以证明普遍提升。

## 结果

| 测试 | 不用 Skill | 用 Skill | 观察 |
| --- | ---: | ---: | --- |
| Case A（12 项） | 10/12 | 12/12 | Skill 组明确说明免费开放工位不含会议室、关键判断附来源日期；两组都没有把免费工位或事后补贴当成可直接降低成本的方案。 |
| Case B（10 项） | 8/10 | 10/10 | Skill 组把独立小办公室保留为**须先澄清合同歧义和费用的联系备选**，并写出材料日期；基线组因最短三个月与逐月退出要求冲突将其排除。两组都排除了 12 个月固定工位，没有套用过期免费工位。 |

### 评分说明

- Case A 基线组未明确指出免费开放工位的会议室也不包含（A-3）；没有在关键判断旁给出材料日期（A-11）。
- Case B 基线组没有把石桥小办公室列为值得联系的待核查备选（B-4）；来源有文件链接，但没有写材料日期（B-10）。B-4 存在解释空间：若“可每月停止”绝不允许三个月最低期限，基线组的谨慎排除合理；若报价中“任一整月结束可退租且不承担余月费”有效，Skill 组的先联系澄清合理。分数是按**预先固定**的 rubric，不表示基线组在该点犯了确定错误。
- 两组在预设的严重错误列表中均未触发明确违规。

## 预设 rubric 之外的新发现

1. **Skill 组 Case A 有签约现金算术／口径错误。**答复列押金 7000 元、首月预付租金 3500 元，却写“已知签约现金支出至少 10750 元”。按列出的两项应为 **10500 元**；差额 250 元可能是管理费，但材料没有证明签约时也必须预付该费。预设 rubric 没有这一项，不回改分数，但这是实际质量缺陷。
2. **Case B 的前期预算口径需要更清楚。**Skill 组称押金 2400 元加“若签约时须付首月租金”则首笔 4800 元超过 3000 元上限；但用户的 3000 元写为“前期押金及不可退支出”，是否另含正常首月租金并不确定。`check_candidates.py` 的 `upfront_max` 明确不含首月租金。应分别列**前期费和押金预算**与**签约时实际现金需求**，不要把两种上限混为一项，也不能假设首月付款时点。
3. **案例未覆盖最重要的发现能力。**目前证实的是材料审查有所改善；用户最关心的跨区域主动找到申请型免费空间、与商业供给同表比较，尚未做有／无 Skill 对照。

## 下一步建议

先用一般规则修正“费用逐项列式、签约现金与前期预算分开、付款时间未知则不下结论”，避免针对这两个虚构地点写特例。随后做一个**未提供候选材料**的跨区域实时搜索对照，并在测试前固定检索范围与评分标准；评价是否找到了运营方的具体免租／付费方案、现行申请条件和联系入口，而不是看答案是否写了“免费”。
