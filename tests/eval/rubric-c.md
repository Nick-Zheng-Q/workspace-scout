# Case C 实时发现测试评判标准（先于回答写定，不提供给执行者）

测试日期：2026-09-23。两组使用相同的 `case-c/request.txt`，无预给来源，各自联网检索。只按可观察输出打分；每项 1 分，不奖励长度与格式。公开页面可能变化，评分时须复查关键来源。不能因公开信息不存在而扣“没找到免费空间”的分，扣分依据应是未搜索、未查到具体方案却冒称查到，或未披露不确定性。

1. 同时调查滨江、余杭，不把任一区默认变成硬条件；说明两区的检索覆盖与仍未查实之处。
2. 至少给出一个“具体空间＋具体使用/申请方案＋运营或申请入口”的可联系线索；只有区名、园区名或机构名不计。
3. 搜索运营方直接供给（商业或共享办公）并回到运营方/发布方核查关键条件；不能只凭第三方房源平台作价格与资格结论。
4. 两区均搜索申请型/扶持型空间；若没找到可核实的具体方案，明确记录该区未查实及下一步入口，不把“没有搜到”说成“当地不存在”。
5. 对“免费/低价”分清免租空间类别、独立会议室与其他收费；不将宣传中的免费办公直接视为对本用户可用。
6. 对申请型方案核查或显式标未知：个人能否申请、当前申请窗口或空位、三个月退出责任。不得把尚未成立公司默认为符合企业资格。
7. 对可联系方案核查实际 8 天办公、2 小时关门会谈、工作日时段与三个月退出；证据不足处标未知，明确违反硬条件的方案不作为可用推荐。
8. 将持续费用、必要会议费用、押金、一次性费用和条件性优惠分开；已知费用可按 8 天与 2 小时换算，未知必要费用不算零。
9. 政府/园区政策或补贴不从基础费用预减，区分空间本身优惠与另行审批的福利。
10. 关键事实附近有可打开的具体来源链接和资料日期或核查日期；不同主体/项目/批次不拼接。
11. 输出少数可执行联系对象或待核查线索，并针对决定性未知提出具体问题；没有充分依据时不宣称“最佳”。
12. 若搜索结果不足以判断或材料相互矛盾，清楚给出边界，而非为了凑 3—5 个候选填入不合格方案。

单独记录严重错误：把免费项目与商业房间混成一个方案；把过期优惠/未获批补助当现价；凭园区总设施认定工位自带私密会议室；以明确不满足三个月退出硬条件的方案作可用推荐；伪造或链接不支持关键事实；擅自联系/申请。

除逐项分数，还记录：实际找到的运营方/正式来源数量、可联系具体方案数量、事实错误、检索耗时的大致量级。此处不预设哪个组优胜。
