# Case D 搜索指导修订前／后对照的预设标准

写定于执行前。两个独立 agent 使用同一实时搜索请求；旧组读 `case-d/skill-before-search-guide.md` 与其中引用的公共 references，但不得读 `references/search-guide.md`；新组读当前 `SKILL.md` 和所引用的 `references/search-guide.md`。两组不得读评分标准、其他测试结果或彼此答案。只按输出及可复核来源评分，不因答案更长而加分。

每项 1 分，共 12 分：

1. 建邺、江宁均查，不提前选区；分别交代检索覆盖及未查实处。
2. 两区都考虑直接供给（运营方的日票、工位、房间或会议室方案），不能只给平台房源。
3. 两区都考虑申请型／扶持型空间；找不到可核实当前方案时明确写未查实，而非宣称不存在。
4. 至少一个值得联系对象具体到空间地址／网点＋使用方案＋可核实公开运营或申请入口。
5. 对媒体／平台线索至少一例展示追查结果：找到同一方案的现行运营／正式页面，或明确说明追不到，不把线索当资格证据。
6. 免费／低价工位不自动等于个人已获准、会议室免费、总费用为零；申请窗口和当前名额不明时标未知。
7. 不能把不同空间、不同房型或不同批次的费用与权益拼成一个候选。
8. 对商业方案按 7 天办公＋2 小时关门会谈估算已知月费；“起价”与报价分开，未知必要费用不记作零。
9. 保密会谈能否预约、9:00—18:00 使用、三个月可退出作为决定性条件核查；不明则未知，明确冲突则不当作可用方案。
10. 押金、一次性费和预付费用分开，不能在证据不足时认定签约现金或前期预算已满足。
11. 关键事实有可打开且确实支持该事实的来源，注明材料或核查日期；不能只引用新闻支持现价／资格。
12. 输出少数可执行的问题和联系顺序；当证据不够时不宣称已找到完全合格／最佳方案。

严重错误单列：虚构具体供给或联系入口；把过期／未获批的免费项目当可用；把会议室、免租或申请资格从别的方案移植；推荐明确违反三个月硬条件的方案；已知必要费用漏算并宣称达标；擅自联系或提交资料。

另记观察：两区每类来源各有多少具体方案；正式／运营方来源数；新闻线索追到现行页面的比例；失效或不支持引用数；答复的可行动程度。不以候选总数单独评优。
